\section{What parts 7 and 8 are for}
%=====================================================================

The project asks whether the text of an earnings release tells us anything about the stock's
abnormal return that the earnings surprise does not, and whether language models do this better
than simple text models, or only appear to because they memorised outcomes.

\begin{itemize}
  \item \textbf{Task 7} builds the simple benchmarks a language model has to beat (surprise only,
  Loughran--McDonald tone, TF-IDF) and compares every model on the same sample, with the same
  metrics, windows and chronological splits.
  \item \textbf{Task 8} merges model scores with the event-level financial data and runs the
  tests: regressions controlling for the surprise and firm characteristics, a $2\times2$ table
  (surprise sign $\times$ text sign), robustness checks, and the 2022 rate shock.
\end{itemize}

\noindent The four claims the design is built to test, in increasing order of strength:

\begin{center}
\begin{tabularx}{\linewidth}{@{}lYY@{}}
\toprule
& Claim & Test \\
\midrule
A & Text is related to returns & Rank IC, long-short spread \\
B & Text adds information \emph{beyond the surprise} (the core claim) & Text coefficient with SUE deciles; combined vs surprise-only out of sample (Clark--West); $2\times2$ table \\
C & LLMs beat simple text models & Same comparison: LLM vs Loughran--McDonald vs TF-IDF \\
D & It is real, not an artefact & Robustness grid, day $-1$ placebo, one run on the frozen holdout \\

\section{Design in brief}
%=====================================================================

The rationale is in \code{docs/METHODOLOGY.md}; the essentials are:

\begin{enumerate}
  \item \textbf{A strong surprise benchmark.} SUE enters as decile dummies because the return
  response is S-shaped. A linear benchmark would let text models win by capturing that curve.
  \item \textbf{Every model graded the same way.} One panel of events. Each signal is converted to its
  within-quarter rank in $[-0.5, 0.5]$, so a 1--5 LLM grade, a dictionary tone and a TF-IDF
  prediction are comparable. Comparisons use \emph{common support}: only events every model scored.
  \item \textbf{Nothing sees the future.} Trained models are fitted on earlier years only
  (expanding window), with a 100-day embargo so a training label's 60-day return never overlaps the
  test period. Tuning uses the development years only. The holdout (2021--25) needs two keys to
  open. A day $-1$ placebo catches timing errors.
  \item \textbf{Inference respects clustering.} Releases cluster in quarterly seasons that share
  market news, so statistics are computed within season and seasons are the independent units
  (Newey--West, 2 lags). Regressions use two-way clustering by firm and season, with Fama--MacBeth
  as a check. Validation has only 12 seasons: below $|t|=3$ we say ``suggestive''.
\end{enumerate}

\noindent Reading: the surprise is strongly priced at release and shows no post-announcement drift
in 2017--19. It also predicts the day $-1$ return, consistent with pre-announcement drift
(leakage or anticipation). That is why the placebo is reported \emph{controlling for SUE}: a text
signal only fails the placebo if it predicts day $-1$ beyond what the surprise does. The out-of-sample
$R^2$ of the surprise-only decile model on the reaction is 8.7\%: this is the bar text models have
to raise.

\subsection{Decisions to write down before the freeze}

These must be fixed in \code{docs/METHODOLOGY.md} (ideally agreed with the instructor) before the
holdout is opened; afterwards they cannot change.

\begin{enumerate}
  \item \textbf{Headline outcome.} Proposed: \code{car_0_1_ff4} (reaction) as primary; the 60-day post-release window as secondary.
  \item \textbf{Main sample.} \code{in_primary} (3+ analysts) vs the broader sample; with or without
  the \code{basis_suspect} and \code{timing_suspect} events.
  \item \textbf{Main LLM signal.} Which model, prompt and variant (\code{raw} vs \code{mask}) is the
  headline in the $2\times2$ table and the regressions. The others become robustness rows.
  \item \textbf{Size filter.} Whether to drop micro-caps (e.g.\ below the NYSE 20th percentile).
  \item \textbf{Multiple testing.} How many signals $\times$ windows are ``primary''; the rest are
  labelled exploratory.
  \item \textbf{Interpretation table.} What each pattern of results would mean (priced in vs
  under-reaction vs memorisation), written before seeing the holdout.
\end{enumerate}

\subsection{Extensions not yet built (own work, optional)}

\begin{itemize}
  \item \textbf{Tradable portfolio.} Current long-short uses same-quarter ranks (fine for
  measuring information, not a strategy). A version with breakpoints from trailing releases only
  would give an implementable return.
  \item \textbf{Book-to-market control.} Needs Compustat \code{ceqq} from part 3--4; then one line
  in \code{regressions.CONTROLS}.
  \item \textbf{FactSet consensus robustness.} If part 3 provides it, add an alternative \code{sue_*}
  column to the robustness grid.
  \item \textbf{Figures for the report.} Cumulative abnormal return by text tercile within beat/miss
  (event-time plot), IC by season over time.
  \item \textbf{Initial git commit.} The repo is initialised and staged but not committed.
\end{itemize}

\section{How to continue}\label{sec:next}
%=====================================================================

All commands run from the folder \code{7_8_baselines_evaluation/}.

\begin{enumerate}
  \item \textbf{Now:} download the Loughran--McDonald master dictionary into \code{resources/lm/},
  then \texttt{python code/pipeline.py -{}-step all}. Check \code{results/tables/}.
  \item \textbf{When part 5 delivers more texts:} rerun \texttt{-{}-step all}. Sanity-check the TF-IDF
  top terms (they should be words like ``impairment'', ``raised guidance'', not firm names), text
  coverage by year, and the placebo row.
  \item \textbf{When part 6 fills the model cache:} \texttt{python code/pipeline.py -{}-step evaluate}.
  LLM signals appear automatically in every table.
  \item \textbf{Make the decisions above} and record them in \code{docs/METHODOLOGY.md} and
  \code{docs/CHANGELOG.md}.
  \item \textbf{After the freeze, once:}\\
  \texttt{UNLOCK\_HOLDOUT=1 python code/pipeline.py -{}-step all -{}-eval-split holdout}, then run
  \code{08b_rate_shock.ipynb}.
  \item \textbf{Hand over to part 10:} the \code{.tex} tables in \code{results/tables/} can be
  \texttt{\textbackslash input} directly into the report.
\end{enumerate}
